User wants a complete KalaCUBE portal redesign inspired by muse.tv (cinematic visual direction studio site).

**Key muse.tv design traits to adopt:**
- Dark, immersive canvas with warm gold accents (#cda45c)
- Video-forward hero with ambient cinematic motion
- Editorial serif typography (Cinzel, Cormorant Garamond, Spectral, Playfair Display)
- Frosted glass navbar with gradient + backdrop-blur
- Restrained motion — only subtle hover transitions, no flashy scroll animations
- Full-bleed fluid grid, portfolio-as-experience layout
- Gallery-at-night atmosphere

**Why:** The current UI is a utility-first rose-colored MVP. The user wants art to feel LIVE — immersive, cinematic, gallery-like. KalaCUBE is "LinkedIn for Artists" and the UI should reflect the artistic community it serves.

**How to apply:** Module-by-module redesign building on top of existing NestJS backend + Next.js frontend. Don't reinvent — enhance. Start with visual overhaul of existing pages, then add new modules.
