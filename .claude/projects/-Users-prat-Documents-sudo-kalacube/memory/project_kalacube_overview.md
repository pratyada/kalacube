KalaCUBE = "LinkedIn for Artists" with 3 art dimensions (the "CUBE"):
1. Handicraft
2. Visual Art
3. Performing Arts

"Kala" = Art (Sanskrit/Hindi), "CUBE" = 3 dimensions of art

**Why:** To create a professional networking and showcase platform specifically for artists, curators, and art spaces.

**How to apply:** All features should revolve around these 3 art dimensions. User roles: superadmin, admin, curator, artist, art-space, user. Database is MongoDB. Original project was barely started — user wants a complete rebuild module by module.
